# Sampath Ayurvedha — NRV concept

Sinhala-first ecommerce prototype. Static HTML, CSS and JavaScript, hosted with GitHub Pages.

This is an independent design demonstration, not an official Sampath storefront. No real orders or payments are processed. Product photos and source notes appear in the prototype; current stock, catalogue, prices and delivery methods require owner confirmation.

Only basket selections and language preference are kept in browser storage. Checkout details are never transmitted or persisted.

Edit `index.html`, `style.css` and `app.js`; assets live in `assets/`. Push to `main` to update the Pages site.
